# 左轨产品图放这里

页面会自动读取下面五个文件，**文件名就是位置**：

```
assets/products/
├── 01.jpg   → 第 1 幕（对应 hero.mp4）
├── 02.jpg   → 第 2 幕（card-01.mp4）
├── 03.jpg   → 第 3 幕（card-02.mp4）
├── 04.jpg   → 第 4 幕（card-03.mp4）
└── 05.jpg   → 第 5 幕（card-04.mp4）
```

丢进去、刷新页面就生效，不用改任何代码。

## 尺寸建议

| 项 | 值 |
|---|---|
| 比例 | **正方形 1:1**（不是正方形会被裁切） |
| 像素 | **≥ 400 × 400**（卡片显示 164px，2 倍屏需要 328px，留点余量） |
| 格式 | `.jpg` / `.png` / `.webp` |
| 体积 | 单张 < 150 KB（这里 5 张同时在场） |

## 两种图怎么选

**实拍图 / 带背景的产品图**：直接放，`object-fit: cover` 会自动裁成正方形，和参考图里 IL MAKIAGE、Grüns 那种"色块背景 + 产品居中"的效果一致。

**透明背景的抠图 PNG**：需要改一处 CSS，否则透明区会变成黑边：

```css
.tile-img{ object-fit: contain; padding: 12px; }
```

改完还能保留卡片底下的渐变色块。

## 想用别的文件名

如果不想改名，就改 HTML 里这五行：

```html
<img class="tile-img" src="assets/products/01.jpg" alt="" loading="lazy">
```

## 找不到文件会怎样

图片路径不存在时，JS 会把这个 `<img>` 摘掉，露出底下的字母占位（S / G / M / E / W）和渐变色块——不会出现裂图标。
